# Glossário

| Termo | Significado |
| --- | --- |
| Orçamento | Proposta enviada ao cliente, com validade. Vira pedido quando aprovada. |
| Pedido | Venda confirmada. Gera OS, nota fiscal, título a receber e comissão. |
| OS | Ordem de serviço: a instalação feita pelo técnico. |
| Comissão | Valor devido ao vendedor sobre a venda ou o recebimento. |
| Fechamento | Consolidação mensal das comissões de um vendedor. |
| Lista de preço | Tabela de preços aplicada a um tipo de cliente (`ClientTypeID`). |
| Título | Conta a pagar ou a receber no financeiro. |
| Virada | Dia em que a MarketUP para de receber lançamentos e o RDX assume. |
| ID MarketUP | Número inteiro que identifica o registro na MarketUP e é mantido no RDX. |
