# Layout e telas

## Coluna fixa (requisito)

Todo conteúdo fica numa coluna de **até 992px**, centralizada à direita do menu lateral (88px recolhido; aberto, 230px com nomes + painel de subitens de 220px), igual à MarketUP. Barra superior de 64px. As barras de ação de cima e de baixo têm a mesma largura.

## Listagem (modelo MarketUP)

| Elemento | Medida |
| --- | --- |
| Faixa de topo | fundo `line`, 24px acima e abaixo |
| Módulo / título | 16px semibold maiúsculas / 30px bold maiúsculas `primary` |
| Barra de ferramentas | 152px: busca + filtros, blocos de 76×76, "Adicionar novo" 152×152 |
| Cabeçalho da tabela | 72px, 14px bold maiúsculas |
| Linha | 110px, faixa de status de 10px à esquerda, número 24px, conteúdo 18px |

## Formulário (modelo MarketUP)

| Elemento | Medida |
| --- | --- |
| Bloco de cabeçalho | borda `primary`, quadro de status de 136px |
| Título de seção | 30px regular, 40px entre seções |
| Grade | 4 colunas, 28px entre colunas |
| Campo | 34px, rótulo PT Sans Narrow 14px |
| Busca principal | 66px, texto 36px |

Fontes: Bai Jamjuree (interface), PT Sans Narrow (rótulos), JetBrains Mono (IDs).
