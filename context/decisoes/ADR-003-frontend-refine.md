# ADR-003: Front-end em React + Refine Core + shadcn/ui

- **Status:** Aceito em 07/11/2026.

## Decisão

- React + TypeScript com **Refine Core** (MIT), visual **shadcn/ui** com os tokens RDX e ícones **Tabler**.
- Ponto de partida: o template de CRM do Refine, traduzido, com o visual trocado e os dados vindos da API Django.

## Por quê

- O Refine entrega prontos listagem, formulário, filtros, paginação, login e permissões.
- É gratuito para uso comercial; os planos pagos do Refine AI não são usados.
- As telas seguem as medidas da MarketUP (`../design-system/layout-e-telas.md`).
